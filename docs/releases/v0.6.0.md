# Trestl v0.6.0

Trestl v0.6.0 adds screenshots and Markdown diagrams to work item discussions.

- Use **Add image** or paste a screenshot into a work item description or comment. The editor inserts an image link at the cursor, and the saved item displays the image inline.
- Render fenced `mermaid` and `flowchart` diagrams in descriptions, comments, and comment previews. Flowcharts, sequence diagrams, and other Mermaid diagram types use the same Markdown rendering path.
- Keep images within work item access rules. PNG, JPEG, GIF, and WebP files are supported up to 8 MB each, with 1 GB of image storage per workspace. Removing an image link revokes access for other work item viewers.

See [PR #35](https://github.com/saynain/trestl/pull/35) for screenshots of descriptions, comments, and rendered diagrams.

## Upgrade notes

Back up the installation database before upgrading. The server creates its image table automatically; no new environment variable or manual migration is required. Uploaded image bytes live in the installation database and count toward its storage and backup size. Deleting a work item deletes its attached images; unused uploads are removed after seven days on a later upload.

Project transfers include Markdown text but not uploaded image bytes. Re-upload screenshots after importing a project into another installation. The image API adds `POST /api/v1/images` and `GET /api/v1/images/{id}` under the existing `/api/v1` prefix; existing endpoints remain compatible.

## Downloads and desktop alignment

The web image is `ghcr.io/saynain/trestl:v0.6.0` for `linux/amd64`. Pin the published digest in deployment repositories. The CLI archive `trestl-cli-0.6.0.tgz` and `SHA256SUMS` are attached to this release, with the same package mirrored at `ghcr.io/saynain/trestl-cli:v0.6.0`.

The desktop app, bundled server, root package, CLI package, Tauri config, and Cargo manifest are aligned to **0.6.0**. Signed desktop installers and the updater feed remain pending signing configuration. Test installers from successful **Desktop installers** workflow runs require repository access; they are not signed release downloads. See the [desktop guide](https://github.com/saynain/trestl/blob/v0.6.0/docs/desktop.md) for platform requirements and signing status.

## Verify locally

From a checkout of `v0.6.0`, run `pnpm install --frozen-lockfile`, `pnpm test`, `pnpm build`, and `pnpm desktop:version`. Start `pnpm dev` with an isolated data directory. Create a work item, paste a screenshot into its description, and save it. Add another image in a comment. Confirm both render after reload. Add a fenced `mermaid` flowchart and sequence diagram in a description and comment, and confirm the comment preview and saved item display them.
