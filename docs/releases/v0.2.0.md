# Trestl v0.2.0

This release adds customizable boards and improves everyday work item editing, project actions, and people administration.

## Boards

- Rename, reorder, and show or hide column headings; choose compact cards, tag visibility, and completed columns. Preferences are saved per user and board in the browser and included in saved views. Renaming a heading preserves the underlying status. ([#4](https://github.com/saynain/trestl/pull/4))
- Drag cards within or between columns, or use Alt + Up/Down to reorder a focused card. Card order persists across reloads. ([#4](https://github.com/saynain/trestl/pull/4))

## Work items

- Save title and description edits with Cmd+Enter or Ctrl+Enter. ([#1](https://github.com/saynain/trestl/pull/1))
- Toggle Markdown task checkboxes with a click or Space while preserving the surrounding text. Descriptions managed by GitHub or Gitea remain read-only. Borderless text fields now retain their intended focus styling. ([#2](https://github.com/saynain/trestl/pull/2))
- Set an optional Start date when creating work. ([#3](https://github.com/saynain/trestl/pull/3))
- Read descriptions, comments, and properties with larger text. Activity appears as a chronological timeline, and comments have Write/Preview controls that preserve drafts. ([#7](https://github.com/saynain/trestl/pull/7))
- Edit tags with roomier chips and reliable removal when additions are pending. Long names wrap, and failed saves retain the draft. ([#5](https://github.com/saynain/trestl/pull/5))

## Projects and people

- Edit projects directly from All projects. Import sits beside New project, and Export is available from the project options menu on every project tab. ([#6](https://github.com/saynain/trestl/pull/6))
- Search people by name or email, filter active and disabled accounts, and create accounts through an Add a person dialog. Role and authentication controls use the shared picker. ([#8](https://github.com/saynain/trestl/pull/8))
- Disabled accounts cannot receive new assignments. Existing assignments remain editable and can be reassigned; recurring follow-ups become unassigned if their previous assignee is disabled. People with the same name are distinguished by email. ([#8](https://github.com/saynain/trestl/pull/8))

## Upgrading from v0.1.0

Back up your database and retain `APP_SECRET` before upgrading. This release adds no database migration or new required environment variable. Existing projects and work items are retained. The API remains under `/api/v1`; new assignments to disabled users are now rejected.

Deploy the application image `ghcr.io/saynain/trestl:v0.2.0`, using the verified registry digest in deployment configuration. The published image supports `linux/amd64`. Download `trestl-cli-0.2.0.tgz` and `SHA256SUMS` from this release, verify the checksum, and install with:

```sh
npm install --global ./trestl-cli-0.2.0.tgz --ignore-scripts
trestl --version
```

The same CLI package is available as the OCI artifact `ghcr.io/saynain/trestl-cli:v0.2.0`. Node.js 22.9+ is required. Neither publishing a release nor replicating its artifacts automatically updates a running installation.
