# Trestl v0.3.0 (upcoming)

Planned changes for the next release. This release has not been published.

## Canvases

- Import `.excalidraw` files directly from a project's Canvases overview. Each import creates and opens one canvas, using the filename and selected collection, without leaving a blank canvas behind. Invalid files create nothing. ([#10](https://github.com/saynain/trestl/pull/10))
- Manage canvases from the CLI with `trestl canvases list|create|import|show|delete`, using project keys or repository defaults. `show` prints a browser link, and deletion requires the revision previously read. ([#10](https://github.com/saynain/trestl/pull/10))
- Import native Excalidraw documents through `POST /api/v1/projects/:projectId/canvases/import`. Retrieve a canvas link and revision through `GET /api/v1/projects/:projectId/canvases/:canvasId/show`. Existing project permissions, token scopes, and scene limits apply. ([#10](https://github.com/saynain/trestl/pull/10))

The canvas changes require no database migration or new environment variable. Update both the server and CLI to use the new commands and endpoints.
