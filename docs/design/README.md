# Design references

The images in this folder are early design references, not screenshots of the current app. They show navigation that never shipped: a workspace picker below the logo, a project tree and saved Views in the sidebar, and a Settings link.

The current sidebar has Home, Inbox, Notifications, My work, Projects, People and Favorites, with Administration and the account menu at the bottom. Projects have the tabs Overview, Work items, Board, Gantt, Resources, Canvases and Roadmap. The sidebar is being redesigned in [#89](https://github.com/saynain/trestl/issues/89).

The [interface specification](design-system.md) describes the palette, type and layout these renders are based on.
